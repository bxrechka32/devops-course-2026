# VS Code и Git: заметки

## Удобно в VS Code
1. Панель Source Control: видны все изменённые файлы, их можно добавить в индекс по одному (или даже отдельные строки) одним кликом.
2. Встроенный diff: изменения подсвечиваются рядом со старой версией файла, сразу видно, что поменялось.
3. GitLens: git blame прямо в строке кода — кто и когда её изменил, плюс история файла и сравнение веток.

## Удобнее в терминале
- Сложные операции с историей: interactive rebase, cherry-pick, reflog, поиск по логу с фильтрами. В терминале это быстрее, а команды одинаково работают и на сервере по SSH.
